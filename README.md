# 📄 Canva Style CV Builder

Ένας σύγχρονος, διαδραστικός και πλήρως responsive δημιουργός βιογραφικών σημειωμάτων (CV Builder) κατασκευασμένος με HTML, JavaScript και Tailwind CSS.

## 🚀 Χαρακτηριστικά (Features)

* 🎨 **7 Διαθέσιμα Templates**: Επιλογή ανάμεσα σε Canva Burgundy, Modern Slate, Minimal Classic, Executive Emerald, Corporate Blue, Elegant Serif, και Tech Monospace.
* 🔄 **Δυναμικός Αλγόριθμος Overflow**: Αυτόματη μεταφορά περιεχομένου (spillover) από την αριστερή στη δεξιά στήλη και δημιουργία 2ης σελίδας A4 όταν γεμίσει το περιθώριο.
* 🛠️ **Πλήρης Προσαρμογή**: 
  * Αλλαγή γραμματοσειρών (Fonts) με υποστήριξη Ελληνικών & Αγγλικών.
  * Προσαρμογή χρωμάτων (Primary, Banner, Text, Decorative Circles).
  * Ρύθμιση μεγεθών γραμματοσειράς (Base, Headings, Title).
* 📝 **Πλήρως Επεξεργάσιμα Πεδία**:
  * Στοιχεία επικοινωνίας & Φωτογραφία προφίλ.
  * Προφίλ & Επαγγελματική Εμπειρία (με επεξεργάσιμη τοποθεσία/location).
  * Εκπαίδευση, Σεμινάρια & Ξένες Γλώσσες.
  * Δεξιότητες & Άδειες Οδήγησης με δυναμικά sliders.
* 📱 **PC & Mobile Friendly**: Ομαλό scrolling με τη ροδέλα του ποντικιού (mouse wheel) σε υπολογιστές και άψογη απόκριση σε κινητά.
* 🖨️ **Print & Export to PDF**: Έτοιμο για εκτύπωση ή αποθήκευση ως PDF με διατήρηση των διαστάσεων A4.

## 🛠️ Τεχνολογίες

* HTML5
* JavaScript (Vanilla JS)
* Tailwind CSS (via CDN)
* Google Fonts
